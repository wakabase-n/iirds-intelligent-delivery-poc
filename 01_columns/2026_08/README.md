# iiRDS Intelligent Delivery PoC（2026年8月号 実証検証データセット）

本リポジトリは、テクニカルコミュニケーションおよびAIガバナンスにおける「V3（従来のパッキング型RAG）」と「V4（iiRDS Atomic Data v1.2 ＋ ナレッジグラフによるHybrid RAG）」の比較検証、および「根拠追跡型例外管理監査」の再現実験用データ一式を公開している公式リポジトリです。

---

## 📌 リポジトリ構成

```text
01_columns/2026_08/
├── data/              # 実証用データソース（V3 / V4 / ナレッジグラフ）
├── prompts/           # アトミック化・グラフ生成・監査用メタプロンプト群
└── test_results/      # TEST A〜Cの実証ログおよび例外管理監査レポート
```


### 1. `data/` （データソース）

- **`manual_v3_RAG_Optimized.md`**: 従来の人間向けにパッキング（結合）されたドキュメントデータ（V3）
- **`manual_v4_Atomic_Data.md`**: `iiRDS Atomic Data v1.2` に基づき16個に原子化・単一責任化されたデータ（V4）
- **`manual_KnowledgeGraph.md`**: DIN SPEC 91526準拠のSPO（主語・述語・目的語）構造化トリプルデータ

### 2. `prompts/` （プロンプト定義）

- **`Build_iiRDS_Atomic_Data.md`**: 標準アトミックデータ生成プロンプト
- **`Build_iiRDS_Atomic_Data_r1.md`**: **【完全強化版】** `property`/`value` ペア構造化に対応した高解像度アトミック化プロンプト（「5mmの沈黙」対策）
- **`Build_KnowledgeGraph.md`**: チャンク直結型標準ナレッジグラフ生成プロンプト
- **`Build_KnowledgeGraph_r1.md`**: **【プロンプト・デルタ】** `ex:hasAttribute` による多層属性接続ルール適用プロンプト
- **`Build_Audit_Report.md`**: 根拠追跡型（トレース可能）例外管理監査用プロンプト
- **`NotebookLM_template_query_for_V3.md` / `for_V4.md`**: 実証用検索・抽出クエリテンプレート
    

### 3. `test_results/` （検証結果・監査レポート）

- **`TEST-A_V3_実験結果.md` / `TEST-A_V4_実験結果.md`**: 単純質問における他機種情報混同（エッジ汚染）の比較検証
- **`TEST-B_V3_実験結果.md` / `TEST-B_V4_実験結果.md`**: ガードレール機能（論理遮断）の比較検証
- **`TEST-C_V3_実験結果.md` / `TEST-C_V4_実験結果.md`**: 属性掛け合わせ（パーソナライズ抽出）と構造不和（インピーダンス・ミスマッチ）の比較検証
- **`999_Insight_Audit_Report.md`**: 16チャンクを対象とした例外管理監査レポート実証結果

## 🛠 追試・再現手順（How to Replicate）

1. **アトミックデータの生成**
    - `data/` 内の生テキストに対し、`prompts/Build_iiRDS_Atomic_Data_r1.md` を投入して構造化JSONを出力させます。
2. **ナレッジグラフの生成**
    - 生成されたアトミックJSONに対し、`prompts/Build_KnowledgeGraph_r1.md` を投入してSPOトリプルを抽出します。
3. **ハイブリッドRAG抽出テスト**
    - LLM（ChatGPT / Gemini / NotebookLM等）に対し、データセットと `prompts/NotebookLM_template_query_for_V4.md` の指示を合わせて投入し、TEST A〜Cのクエリを実行します。
4. **例外管理監査の実行**
    - アトミックデータとグラフに対し `prompts/Build_Audit_Report.md` を投入し、信頼度スコア付きの監査レポートを出力させます。
