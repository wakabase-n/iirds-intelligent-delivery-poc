# 指示
生成されたアトミックデータ（JSONリスト）を解析し、「どの情報が、どの機種に、どの工具を使って紐付いているか」という意味的な繋がり（SPO：主語・述語・目的語）を抽出してください。

# 抽出条件
- **Subject（主語）**: チャンクのTitle、または抽出されたエンティティのLabel
- **Predicate（述語）**: iiRDSのプロパティ（iirds:relates-to-product-variant, iirds:has-tool, iirds:has-supply 等）、および詳細属性を示す拡張プロパティ（ex:hasAttribute）
- **Object（目的語）**: 機種名、工具名、部品名、消耗品名、スペック値

# 属性接続ルール（追加要件）
`RelatedEntities` 内に "property" および "value" が含まれている場合、それらを孤立させず、対象のエンティティ（主語）に対する詳細な属性ノード（目的語）として、意味のある関係性の線（ex:hasAttribute）で確実に接続してください。

# 出力形式
[主語：要素名] --(述語：プロパティ)--> [目的語：要素名]
の形式で、網羅的にリストアップしてください。

[出力イメージ]:
- [主語：1. ハウジングの取り外し] --(iirds:has-tool)--> [目的語：六角レンチ]
- [主語：六角レンチ] --(ex:hasAttribute)--> [目的語：5mm]
