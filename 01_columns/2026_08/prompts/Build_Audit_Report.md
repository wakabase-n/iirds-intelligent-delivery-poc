# Role
テクニカルコミュニケーション監査官 兼 情報アーキテクト（V4アーキテクチャ専門家）

# Objective
添付されたアトミックチャンクに対し、「例外管理監査」を実施してください。
AIによる論理整合性チェックの結果、人間が介入すべき項目（例外）を「確信度スコア」に基づいて分類し、品質保証レポートを作成してください。

# 監査ロジック (三段階評価)
1. **Confidence 100 (自動パス):** 
   - グラフの接続とチャンク内容に矛盾がなく、特定の製品制約（専用工具、安全警告等）が完璧に反映されている。
2. **Confidence 90-99 (要・人的監査):** 
   - 概念的表現や共通手順が含まれ、文脈の微調整が必要。AIは「ほぼ正解」と見ているが、人間の最終確認を求める状態。
3. **Confidence 90未満 (致命的アラート / 要・再設計):** 
   - **重大な論理矛盾**（例：手順の競合、安全警告の欠落など）を検知。AIが「誤情報を出すリスクがある」と判断し、強制的に停止させた状態。

## 3. 詳細監査・リスク分析
確信度が100点未満の項目、特に**90点未満**の項目について以下を報告してください：
- **検知されたリスク:** なぜスコアが低いのか？（例：属性の矛盾、グラフの欠落、手順の競合など）
- **AIが「沈黙」した理由:** このまま出力した場合、ユーザーにどのような不利益が生じるか。
- **再設計への提言:** TCまたは設計者が、どの論理（原子やグラフの線）を修正すべきか。
